## 2. Technical description (paste into the "软件功能与特点" fields)

**开发的硬件环境:** 通用 PC (Windows 11 / macOS), 内存 8 GB 以上, 硬盘 10 GB 以上。
**运行的硬件环境:** 运行微信 App 的智能手机 (iOS / Android), 内存 2 GB 以上; 也可在 PC 版、Mac 版微信运行。服务端运行在腾讯云微信云开发 (云函数 + 云数据库 + 云存储)。
**开发该软件的操作系统:** Windows 11。
**软件开发环境 / 开发工具:** 微信开发者工具 (小游戏项目), Node.js 24, Visual Studio Code, node:test 测试框架, @napi-rs/canvas (仅开发期预览)。
**该软件的运行平台 / 操作系统:** 微信 (iOS 与 Android 客户端, 小游戏运行环境); 服务端 Node.js 云函数运行环境 (微信云开发)。
**软件运行支撑环境 / 支持软件:** 微信小游戏运行时 (Canvas 2D、云开发 SDK `wx-server-sdk`、云数据库实时推送)。
**编程语言:** JavaScript (ECMAScript 2020, CommonJS 模块)。
**源程序量:** about 20,000 physical lines of program source (see the table below; excluding the prompt bank, generated agreement text, dev-only mock server and about 21,900 lines of automated tests).
**开发目的:** 为微信群聊中的朋友提供一款约三分钟的休闲聚会小游戏: 群友同时在线, 每人出一个题目并画出来, 轮流把上一位传来的画猜成一句话、把一句话画出来, 传完后一起揭晓题目被传成了什么, 增进群聊互动。
**面向领域 / 行业:** 休闲游戏、社交娱乐。
**软件的主要功能:**
1. 开一局 (默认): 同一微信群的 3 至 10 位群友通过群里的卡片进入同一局, 房主开始; 每人从服务端随机给出的 3 个题目中选 1 个 (可换一批, 最多 5 次, 也可自己出题); 之后每轮每人同时接另一条接龙的上一棒 (画或一句话), 轮转规则保证不接到自己的接龙、也不重复接同一条; 选题 30 秒、画 60 秒、猜 45 秒, 时间到自动交出; 全局最长 20 分钟。
2. 慢慢传: 不需要同时在线, 一条接龙由起点和 6 棒组成, 群友在 48 小时内依次接棒, 两个人也能玩。
3. 全屏画板: 6 色基础调色板 (每日可解锁 6 色彩笔)、3 种粗细、撤销、清空; 笔迹以与屏幕无关的网格坐标保存, 在不同尺寸的手机上等比显示。
4. 揭晓: 全部接龙同时揭晓, 先看最后一棒再逐步回看; 笔迹回放、「笑」互动; 非参与者只看到文字预告。
5. 内容安全: 每幅画由服务端按笔迹渲染图片, 每句话和自己出的题目, 在展示给任何其他玩家之前, 先经微信小游戏同步内容安全接口检测; 未通过或未得到结果的内容不展示 (失败即关闭); 本地敏感词过滤; 举报后内容立即对所有人隐藏; 违规累计限制参与; 管理员下架函数、一键暂停内容展示、检测服务故障熔断。
6. 其他: 我的接龙、本群接龙、连续天数、订阅消息提醒、分享卡片 (不含玩家画作)、激励视频与插屏广告、大字模式与高对比度、删除自己的内容。
7. 服务端: 33 个云函数 (房间与回合、慢慢传、审核、举报、管理、清理与定时器等), 18 个数据集合, 3 个定时触发器; 除一个仅限本人读取的进度通知集合外, 所有集合仅云函数可读写。
**技术特点:** 客户端、模拟服务器和云函数共用同一套纯 JavaScript 规则代码 (房间轮转、抽题、笔迹编解码、文本规则; 一致性测试覆盖); 实时同步以「只含进度的门铃文档」加定时轮询兜底, 回合截止时间以服务器为准; 全部界面由代码在 Canvas 上绘制, 无第三方图片素材; 约 530 项客户端自动化测试和 395 项云函数测试。
