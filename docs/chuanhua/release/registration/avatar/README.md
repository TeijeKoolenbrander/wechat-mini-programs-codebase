# 传画接龙 account avatar

Original, code-drawn avatar generated by `build.js` (resvg). No third-party IP, no AI art.

**Design.** A tilted white paper note (with a strip of tape) on a warm-orange field, a wobbling blue doodle line drifting across it and ending in a brush-shaped relay baton: black bristles, silver ferrule, vermilion handle. It is the "brush-baton mascot" of direction §6 reduced to an icon. No text, no face, nothing resembling Gartic Phone's characters, colours or UI.

**Palette.** orange #F7B04B to #EE8A1F, paper #FFFDF8, doodle blue #3C78C8, handle 朱 #D8433B, ink #1E1B18, tape #F2C94C (direction §6 palette).

**Text and font.** None. Pure code-drawn vector shapes, so no font licence is involved.

**Legibility at small size.** At 40 px the white note against the orange field, the blue squiggle and the red brush remain three distinct shapes; the brush is the smallest element and is still recognisable as a diagonal accent. Checked on `preview.png` (360 px square, circle crop, and 40 px and 100 px on light and dark grounds). All content sits inside the central ~0.85 of the circle, so the circle crop WeChat applies in lists loses nothing.

**Files** (square, opaque, sRGB):

| File | Use |

| `avatar-512.jpg` | **upload this** (about 30 KB; JPG is accepted by every version of the form) |

| `preview.png` | the legibility check |

JPG: quality 92, any alpha flattened on white. All files are well under the 2 MB limit.

**Rebuild:** `npm i && node build.js` (Node 18+; `node_modules/` is gitignored). Font only for the 比 glyph in 比一比: Noto Serif SC variable (SIL OFL 1.1), read from `FONT_DIR` (default `C:/Windows/Fonts/NotoSerifSC-VF.ttf`).
