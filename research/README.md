# Research

## Naming convention
- One folder per research round: `YYYY-MM-DD-<topic>/`.
- Inside each round, one numbered file per research angle (`01-...md`, `02-...md`, ...).
- `00-shortlist.md` is the shortlist/decision document that synthesises the round.
- Each round has a `README.md` summarising the brief, files, outcome, status and caveats.
